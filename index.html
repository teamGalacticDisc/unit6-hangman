Before you start
  • Open it on the computer hooked up to the projector. Any browser works and there is nothing to install.
  • The game reads each clue, answer, and bonus question out loud. Turn the projector sound on, or use the Voice button at the top to turn it off. Chrome or Edge have the best voices.
  • Scores save in this browser, so a refresh will not wipe them. Use Reset game in the teacher panel for a fresh start.
  • The teacher panel can add or take away points, undo a mistake, and download the final scores as a CSV file.
