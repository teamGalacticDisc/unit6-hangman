The prompts I used

Edited for spelling and clarity. The requests are the same as the ones I sent.

The game itself. I wrote this one using the Role, Task, Context, Format setup from class, so the AI had everything up front.

Role: You are a game designer and teacher's helper for my ARIN 320 class.

Task: Build a two team Hangman game for Unit 6 where the teams compete head to head. Pull every word and clue straight from the Unit 6 content. Don't make up terms that aren't in the unit.

Context: We play live in class on one shared screen. I can type in the team names at the start. Use 15 to 20 key Unit 6 terms. Each word gets a plain clue, plus a one line fun fact or example from the unit that shows after it is solved. Teams take turns guessing letters. A right letter earns points and keeps the turn. A wrong letter passes the turn to the other team. Either team can try to solve the whole word on its turn. A right solve earns big points, and a wrong solve costs points. Each team gets one steal per game to solve the other team's word. Each team gets one lifeline that reveals a letter. The team that solves a word gets a bonus question from the unit for extra points. A round ends when the word is solved or the drawing is finished. The game ends after a set number of rounds that I choose. Each wrong letter adds a piece to the drawing. Show a live scoreboard, a teacher panel where I can add or take away points, undo the last change, and reset the game, a round by round history, scores saved in the browser, a CSV download, and a winner screen.

Format: One HTML file that opens in any browser with no install. Big text that's easy to read on a projector. Letters work by clicking or typing on the keyboard. Add a short how to play box. List the Unit 6 file each word came from so I can check it.

What I learned: because the prompt spelled out the rules, the scoring tools, and the format, the first version already did what I pictured. The only thing I changed was the drawing.

Why I hosted it on GitHub

We play this together in class, so it needs to open fast on whatever computer is hooked up to the projector. I used GitHub Pages again, the same as my Unit 5 sprint.

  • One link. Open the web address and play. There's nothing to download or install.
  • Always the latest version. When I push a fix, the link has it the next time the page loads.
  • Free, with no server or accounts. The game is one plain web page, so GitHub can host it as is.
  • Open to check. The code is public, so anyone, including my instructor, can see exactly what the game does.

Scores save only in the browser on that computer. Nothing is sent to me or stored online.

Why this matters for Unit 6

Unit 6 says domain knowledge belongs in the design. The AI could write the code, but it only knew what to build because I gave it the course material and the rules for how our class plays. I check the game myself before we play it in class. Nothing goes in front of the class on the AI's word alone.
